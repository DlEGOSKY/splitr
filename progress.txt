1. **Narrador**: si no suena, verificar:
   - Prefs.narrator=true (Settings → Audio → Narrador por voz)
   - Browser soporta speechSynthesis (Safari iOS a veces tarda en cargar voces)
   - User gesture requerido antes del primer speak (ensureAudio() lo cubre)

2. **Replay**: solo fuerza ganador en modos NO overlay (coin/dice/bomb/russian/split
   hacen replay fresco). Ver overlayModes en handleReplay.

3. **Screenshot**: Web Share con files NO está en desktop. Cae a download.
   Probar en mobile real (Safari iOS 16.4+, Chrome Android).

4. **Insights**: se ocultan si no hay ≥3 sorteos. Es feature esperado, no bug.

5. **Moments seasonal**: se activan por fecha real del dispositivo.
   Si no se ven, usar devtools → document.body.classList.add('moment-halloween')
   para probar visual.

6. **Recent groups**: se ocultan si savedGroups está vacío. Es esperado.

7. **Lint warnings "imports unused"**: falsos positivos del IDE mientras
   editaba, se resuelven con build real (tsc).
